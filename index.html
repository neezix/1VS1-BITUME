Récompenses

📱 Téléphone ↔ PC

Ton téléphone devient une manette pour le jeu ouvert sur l'ordi (ou la télé). Sur l'ordi, crée le code ; sur le téléphone, ouvre le jeu et tape le code (ou scanne le QR code).

Envoie ton niveau, tes tenues, ton joueur, l'histoire et le tournoi d'un appareil à l'autre.

Sans internet : code texte

Téléphone contre PC en ligne : sur un appareil, En ligne → Créer une partie ; sur l'autre, tape le code. Ça marche en Wi-Fi comme en 4G, chez toi, au lycée ou chez un pote.

Installer le jeu comme une appli : sur téléphone, menu du navigateur → « Ajouter à l'écran d'accueil ». Sur PC (Chrome / Edge) : icône d'installation dans la barre d'adresse.

Sur la télé : ouvre le jeu sur l'ordi branché à la télé et utilise ton téléphone comme manette (onglet Manette), ou une vraie manette.
